# Proyecto Programación Orientada a Objetos II UNLa - Sistema de Gestión de Turnos

Este proyecto corresponde a la materia **Programación Orientada a Objetos II** de la Universidad Nacional de Lanús (UNLa). Su objetivo princiapl es el desarrollo de un **Sistema de Gestión de Turnos** que permite administrar reservas y asignaciones de turnos para distintas entidades, optimizando la organización y atención de usuarios.

## Requisitos

- Java 17 o superior.
- Librerías de Hibernate.
- MySQL como Base de Datos.
- Crear una Base de Datos ejecutando el script **db_turnos** ubicado en el repositorio.
- Configurar las variables dentro del hibernate.cfg.xml
  - **connection.url**: Colocar la URL de la Base de Datos.
  - **connection.username**: Colocar tu usuario de la Base de Datos.
  - **connection.password**: Colocar tu password de la Base de Datos.
- Ejecutar el TestHBM.java para verificar la conexión a la Base de Datos. Caso contrario al esperado revisar los anteriores puntos.
